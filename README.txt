ZUMA MUSIC WEBSITE PACKAGE

This folder is a portable static website. It does not require GitHub.

Recommended first deployment: Netlify Drop
1. Keep every file and folder together.
2. Upload the entire folder (or this ZIP) to Netlify.
3. Netlify will publish the page and detect the waitlist form.
4. Do not change zuma.music DNS until the new hosted URL has been tested.

The existing links are configured for:
- Contact: hello@zuma.music
- TikTok: @zumamusc
- Instagram: @zumamusc
- X: @zumamusc
- Music: Untitled project link
- Archives: Zuma YouTube channel

The waitlist form uses Netlify Forms. If hosted elsewhere, connect the form to
that provider's form service before accepting real signups.
